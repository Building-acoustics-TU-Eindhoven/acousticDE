# Contributing to acousticDE
We welcome community contributions, bug reports, and questions. For long-term continuity and public visibility, GitHub remains the best place to contribute or seek help.

## Reporting Bugs
If you encounter an error, installation failure, or unexpected behavior, please open an issue. To help us resolve it quickly, please include:
- Your operating system and Python version.
- Any details about your local setup that might be helpful in troubleshooting.
- Detailed steps to reproduce the bug.
- The full traceback of the error.

## Suggesting Features
We welcome ideas for new features. You can suggest a feature by opening a GitHub issue with the title: **Feature request: feature title**. It is important to provide a detailed description of the feature and how this would contribute the acousticDE repository.

## Contributing Code
We gladly accept Pull Requests (PRs) for bug fixes, new features, and documentation improvements.
1. Fork the repository and create a new branch for your feature.
2. Write clean, documented code and include tests for new functionality. Before accepting your changes, the necessary automated tests will need to be performed. 
3. Submit a PR describing your changes. If your PR addresses an open issue, please reference it (e.g., "Addresses #12") in the description.

## Seeking Support
If you have questions about how to use the software, set up a specific simulation, or understand the underlying methodology, please open an issue and apply the **Question label**.
